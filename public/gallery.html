Questions

About the animations.

What do I actually get?

Each animation comes as a detailed build prompt. Copy it, paste it into your AI coding tool, and you get the full production-ready section back — physics, interactions, accessibility and teardown included. Everything running in the gallery above was built from exactly these prompts.

Which AI tools does it work with?

Any tool that writes and edits code for you: Claude Code, Cursor, GitHub Copilot, Windsurf and the like. The prompts are plain text with exact numbers and acceptance checks, so they do not depend on one tool. Results vary a little between models; the prompt says precisely what “done” means so your tool can check its own work.

Do I need a framework or a build step?

No. Every animation is plain HTML, CSS and JavaScript — no framework, no bundler, no npm install. The prompt also tells your tool how to mount it inside React or Next.js if that is what your site runs on.

Can I change the colours, text and speed?

Yes. Brand text sits in one place at the top of each module, and colours and timing are named values, so you can ask your AI tool for “our orange, slower” and it knows exactly what to change.

Does it work on phones?

Yes. Every animation works with touch, stays smooth down to 360px wide, pauses when it is off screen so it never drains a battery, and shows a composed still for people who turn motion off.

Can I try one before paying?

Yes. Impact Grid is free with an account — the whole prompt, not a sample. Every other card also shows the opening of its prompt, so you can see exactly how they are written. Billing questions are answered on the pricing page.
